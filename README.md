# Portfolio

Welcome to Anjal's Portfolio Page. Learn more about who I am and what I enjoy doing! Stay tuned for updates.

## Live site

[anjalparikh.com](https://anjalparikh.com)

## Stack

React 19, TypeScript, Vite, Tailwind CSS, GSAP, Framer Motion, React Router, hls.js.

## Local development

```bash
npm install
npm run dev
```

The dev server runs on port 8001.

```bash
npm run build     # production build to dist/
npm run preview   # serve the production build locally
```
